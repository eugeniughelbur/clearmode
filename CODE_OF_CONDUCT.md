# Code of conduct

## The short version

clearmode is 43 arguable rules. Argue about the rules, not about the people. This repo exists because people disagree about what good writing is, and that disagreement is the useful part.

## Expected behavior

- Bring a concrete example. A sentence the checker got wrong beats an opinion about the checker.
- Assume the other person read the rule and still disagrees.
- Accept that some rules are judgment calls with a threshold, and the threshold is arguable.

## Unacceptable behavior

- Personal attacks, harassment, or discriminatory language
- Publishing someone's private information
- Sustained disruption of discussions

## Enforcement

Report problems to e.ghelbur@gmail.com. Reports stay private. The maintainer may edit, lock, or delete comments, and may block accounts, for behavior that breaks this document.

## Scope

This applies in issues, pull requests, discussions, and any space where someone represents the project.
